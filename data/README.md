# data/

Only small, synthetic sample datasets under `sample/` are versioned.
Everything else in this folder is git-ignored, so your own data never ends up on GitHub.

| File | Description |
|---|---|
| `sample/sales.csv` | 1,012 synthetic sales orders (2025). Generated by `scripts/generate_sample_data.py` with intentional data-quality issues: missing emails and regions, exact duplicate rows, extreme quantities and a few negative prices. |

Regenerate it with:

```bash
uv run python scripts/generate_sample_data.py
```
